# Hotelia

Hotelia est un mini système ERP de gestion hôtelière développé dans le cadre d'un projet universitaire en 4ème année informatique.

Il permet de gérer les clients, les chambres, les réservations et les factures d'un hôtel, avec un système de connexion et de rôles (admin / réceptionniste).

## Technologies utilisées

- Java EE (JEE)
- JPA pour la base de données
- JSP pour les pages web
- MySQL

## Fonctionnalités principales

- Connexion et gestion des rôles
- Gestion des clients
- Gestion des chambres et leur disponibilité
- Réservations avec vérification des dates
- Génération automatique des factures

## Structure du projet

Le projet suit une architecture en couches : Présentation, Service, DAO et Persistance.
